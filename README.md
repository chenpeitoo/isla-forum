# ISLA 美妝電商網站 —— 資展國際「前端工程師就業養成班」期末專題
一個結合電商與社群功能的美妝網站，具備即時聊天室、論壇留言互動、商品購物車與管理後台功能。  
團隊成員：黃士寧、劉啟揚、柴彥廷、陳姵文(我)、許毓尹、宋振瑋  

我負責開發「美妝社群」頁面，主要功能有：  
- 貼文發佈/瀏覽/編輯/刪除/按讚收藏、無限滾動串接  
- 留言區遞迴留言、按讚  
- 即時雙方、多方聊天室  
- 全站響應式設計，支援動態伸縮

網站內容來自網路資源，僅用於學習前端技術，無商業用途，如有侵權敬請告知。
